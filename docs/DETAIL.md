# 习惯挖掘器

把你在对话里**反复纠正 AI** 的做法，整理成 `AGENTS.md` 规则。它只提议，不落笔：每条候选都要你点确认，写进去的每条都能撤回。

## 它解决什么

同一个要求，你今天说一遍「以后都用 pnpm」，下周开新会话又要再说一遍。DSH 的规则文件（`~/.dsh/AGENTS.md` 和各工作区的 `AGENTS.md`）本来是放这些话的地方，但没人愿意边聊边维护它。

装上之后：

1. 你在对话里纠正 AI（「不对，以后都用 pnpm」「以后图表放 diagrams/」），插件在回合结束时把这些话记成线索，**不调模型、不写文件**。
2. 同一件事出现在**第二个会话**里，它才升级成待确认候选。一次性要求（「这次用英文」）不会冒出来。
3. 右侧栏「习惯」页里逐条确认：确认后写进 `AGENTS.md` 的一个插件维护段落，可以改措辞、可以选写「全局」还是「本工作区」。
4. 想反悔：在「已生效」里点撤销，段落里那一条就删掉。

## 和用户画像记忆的区别

用户画像记的是**你是谁**（身份、城市、职业、偏好），进的是 persona 档案、按预算注入。

这里记的是**该怎么做事**（格式、工具用法、禁止事项），进的是 `AGENTS.md`，由 DSH 的指令加载器按工作区读取。两者不共享数据，也不互相依赖，可以只装一个。

## 入口在哪

右侧栏顶部的 **+**（新标签页）→ **习惯规则**。装好后如果右栏没有这一项，重新加载页面（Desktop 里按 Ctrl+R，或重启 DSH）——客户端插件是页面加载时载入的。

## 数据在哪、改了什么

| 位置 | 内容 |
| --- | --- |
| `~/.dsh/habit-miner/` | 线索、候选、审核记录、写入前的快照 |
| `~/.dsh/AGENTS.md` | 「全局」规则（插件维护的段落） |
| `<工作区>/AGENTS.md` | 「本工作区」规则（同段落） |

- 段落用 `<!-- habit-miner:begin -->` / `<!-- habit-miner:end -->` 圈起来，段落外的内容一个字节都不动。
- 每次写文件前先快照到 `~/.dsh/habit-miner/snapshots/`，最多保留 40 份。
- 不联网、不上传、不读别人的数据。

## 已知限制

- **没有 watcher**：`AGENTS.md` 写入后，要等下一次读取该目录、会话恢复、或新开会话才生效。面板会提示这一点，不会假装立刻生效。
- **历史回填有边界**：靠 DSH 的 `sessionQuery` 服务，默认只看 30 天、最多 60 个会话、6000 条消息；没有这个服务的环境只能从新对话开始收集。
- **只做规则，不做代码**：不会替你把习惯变成插件或脚本。
- **不去重你的手写内容**：手写的规则和插件段落并存，重复的话它管不了。
- **相似度是本地算的**：用 SimHash + 字符重合度；不同说法（「装」vs「安装」）能合并，版本号不同的（`pnpm` vs `npm`）不会被误合并。

## 卸载

在插件页卸载即可。已写入 `AGENTS.md` 的规则会保留（它们是你的文件）；想清掉就删掉那个 `<!-- habit-miner:begin -->` 段落，或先在面板里逐条撤销。`~/.dsh/habit-miner/` 可以手动删。
